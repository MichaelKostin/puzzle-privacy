# Puzzle Garden legal pages

Static English and Russian legal/support pages for **Puzzle Garden**.

## Pages

- `/privacy-policy.html` and `/ru/privacy-policy.html`
- `/terms-of-use.html` and `/ru/terms-of-use.html`
- `/support.html` and `/ru/support.html`

The site has no build step. Serve the directory with any static web server.

Before deploying to a custom domain, add a `CNAME` file containing the final hostname.
